# SGV - Sistema de Gestión de Ventas
Aplicación de escritorio/web desarrollada con Python + Flet + SQLite3.

## Módulos incluidos
- 🔐 Login con autenticación
- 📊 Dashboard con KPIs en tiempo real
- 📦 Gestión de Productos (CRUD)
- 👥 Gestión de Clientes + historial de compras
- 🏷️ Control de Inventario (entradas/salidas/ajustes)
- 🛒 Punto de Venta (POS) con carrito
- 🧾 Facturación
- 📈 Reportes de ventas
- 💰 Caja (apertura/cierre de turno)
- 👤 Administración de Usuarios
